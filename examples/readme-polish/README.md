# 一篇项目介绍，两处改稿对照

CrewGPT 最初那版首页由 GPT 起草，DeepSeek 润色，GPT 定稿。以下摘自当时的三个版本。

## 第一句，应用在哪里运行？

| 环节 | 当时的原句 |
| --- | --- |
| GPT 初稿 | CrewGPT 是一个本地 macOS 团队聊天应用。 |
| DeepSeek 润色 | CrewGPT 是一个本地运行的 macOS 团队聊天应用。 |
| GPT 定稿 | CrewGPT 是一款在本机运行的 macOS 团队聊天应用。 |

初稿把“本地”“macOS”“团队聊天”连在一起。DeepSeek 加的“运行”让“本地”有了明确的指向。GPT 定稿时把前半句顺成了“一款在本机运行的”，保留了这处改动。

## 写到作者在几个窗口之间来回传话时

| 版本 | 原句 |
| --- | --- |
| 修改前 | 麻烦的是，我成了传话的人。Claude 缺数据，我去找 GPT。GPT 查到出处，我再转给 Claude。写完还得把稿子贴给 DeepSeek。 |
| DeepSeek | 麻烦的是，我成了传话的人：Claude 缺数据，我去找 GPT；GPT 查到出处，我再转给 Claude；写完还得把稿子贴给 DeepSeek。 |
| GPT 定稿 | 麻烦的是，我成了中间传话的人。Claude 缺数据，我去找 GPT。GPT 查到出处，我再转给 Claude。稿子写完，还得贴给 DeepSeek。 |

DeepSeek 用标点把三次传话串了起来。GPT 定稿时又拆成短句，让读者跟着作者一步一步走。作者对模型的评价，例如“顶级牛马”和“不说人话”，在两轮修改里都保留了。
